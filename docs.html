FAQ

Understand the boundaries.

Does KALKI send or reply automatically?

External actions are intended to happen only after an explicit user request and approval. Live integrations are not generally available; a draft does not mean a message was sent.

Is memory durable and synchronized?

No. The current memory surface is local/scaffold, not a production durable service.

Can I connect WhatsApp, Gmail or social accounts?

Connectors are pending. Do not enter credentials into this public site. Connected status should follow secure authorization and successful verification.

Can I install Android?

This site does not distribute an APK. Wake-word testing continues and target-device runtime has not been physically verified.
