# UI components and design references

This site uses React, Tailwind CSS, Framer Motion, and Lucide React (MIT-licensed). The Spotlight / CardSpotlight treatments are lightweight local implementations of common spotlight interaction patterns, informed by Aceternity UI's publicly listed free Spotlight component. No paid Aceternity assets, code blocks, or page templates are included.

Reference: https://ui.aceternity.com/components/spotlight

The hero motion is CSS perspective plus Framer Motion transforms; it intentionally avoids a Three.js/WebGL dependency so the page remains lightweight and can gracefully render without GPU support.
