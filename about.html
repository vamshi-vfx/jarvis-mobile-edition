About KALKI

A personal assistant taking shape.

KALKI is a chat-first personal AI assistant project bringing an evolving web app, voice interaction and practical tool surfaces into one place—with explicit user approval as a core product boundary.

Why KALKI

Helpful, without hiding unfinished parts.

The goal is to make AI workflows approachable while staying transparent about what is actually wired up. This is a private beta, not a promise of a fully integrated autonomous system.

Product principle

You remain the decision-maker.

External actions should happen only when the user explicitly asks and approves. A preview is not a sent action or proof of account connection.

Current app surfaces

  • Chat-first assistant and voice interface.
  • Everyday tool surfaces and Creator Agent planning/export.
  • Memory is a local/scaffold experience, not production durable memory.
